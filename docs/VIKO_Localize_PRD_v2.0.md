# 1. 제품 배경과 문제 정의

## 1.1 출발점

VIKO는 사용자가 직접 만든 YouTube 한국어 자막 생성 서비스에서 시작했다. 최초 서비스는 영상에서 자막을 생성하는 문제를 해결했지만, 시장에는 이미 자동 자막과 번역 기능이 널리 공급되어 있다. VIKO Localize는 생성 이후 남아 있는 검수와 완성 작업을 독립 제품으로 정의한다.

## 1.2 사용자 문제

- AI가 만든 원문 자막에 음성 인식 오류와 고유명사 오류가 남는다.

- 번역문이 의미는 맞아도 직역투·부자연스러운 말투·잘못된 높임말을 포함한다.

- 번역 후 문장이 길어져 읽기 속도와 한 줄 글자 수 기준을 초과한다.

- 사용자는 전체 영상을 다시 보며 문제가 있는 Cue를 직접 찾아야 한다.

- 여러 영상에서 인물명·제품명·전문용어가 다르게 번역된다.

- 검수·편집·변환·납품이 서로 다른 프로그램과 웹사이트에 분산된다.

## 1.3 문제 문장

| **Problem Statement** 반복적으로 영상을 현지화하는 사용자는 AI 자막 초안을 얻은 뒤에도 전체 Cue를 다시 검수해야 하며, 오류 발견과 수정에 생성 시간보다 더 많은 시간을 사용한다. |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

## 1.4 기회

VIKO Localize는 전체 자막을 새로 번역하는 대신 규칙 위반과 언어 오류 가능성이 높은 Cue를 우선순위화하고, 사용자가 근거와 수정안을 확인한 뒤 적용하도록 한다. 제품 가치는 생성 속도가 아니라 검수 시간 절감과 납품 품질의 예측 가능성에서 발생한다.

| 비교 대상   | 자막 편집기·영상 번역 서비스·전문 로컬라이제이션 QA 도구 |

## 2.3 제품 원칙

- Find first, edit second — 전체를 다시 읽게 하지 않고 문제 Cue부터 보여준다.

- Rules + Language AI — 수치 규칙과 언어 판단을 분리하고 함께 제공한다.

- Explain every fix — 수정안뿐 아니라 기준과 이유를 제시한다.

- Human in control — 의미 변경 가능성이 있는 수정은 자동 확정하지 않는다.

- Korean first — 한국어 입력·출력 품질과 한국어 작업 경험을 우선한다.

- Tool first, workflow connected — 도구는 독립적이되 결과는 다음 도구로 전달된다.

- Export-ready — 결과는 실제 플랫폼과 편집 프로그램에 납품할 수 있어야 한다.

## 3.2 핵심 JTBD

- 외국어 영상을 발견했을 때, 별도의 자막 파일을 찾아다니지 않고 바로 한국어로 이해하고 싶다.

- 자동 번역 자막을 받았을 때, 직역투와 오역 가능성이 높은 부분만 빠르게 고치고 싶다.

- 원문과 한국어 자막을 함께 보며 번역이 실제 발언을 왜곡하지 않았는지 확인하고 싶다.

- 긴 영상에서도 인물명·브랜드명·전문용어가 같은 방식으로 번역되게 하고 싶다.

- 한국어 자막을 SRT·VTT로 내려받거나 영상과 함께 활용하고 싶다.

## 3.3 비대상 고객

- 전문 NLE 수준의 전체 영상 편집이 필요한 사용자

- AI 더빙·립싱크·음성 복제가 핵심인 사용자

- 방송사급 인력 배정과 납품 대행만 원하는 대기업

- 단순 무료 SRT 변환만 사용하고 저장·교정이 필요 없는 사용자

- AI가 원문에 없는 정보나 이름을 추가하지 않도록 원문 근거를 전달한다.
